# Vanilla JavaScript Version

This folder contains the original vanilla JavaScript implementation of the 3D AR Viewer PWA.

## Files

- `index-vanilla.html` - Original HTML file
- `app.js` - Main application controller
- `viewer.js` - 3D viewer module
- `ar-viewer.js` - AR viewer module
- `styles.css` - Original styles
- `service-worker.js` - Service worker for PWA
- `server.py` - Python development server
- `create-icons.html` - Icon generator utility

## Running the Vanilla Version

If you want to run the original vanilla JavaScript version:

```bash
cd vanilla-version
python3 server.py
```

Then open http://localhost:8000 in your browser.

## Note

The main project has been migrated to React. This folder is kept for reference and backup purposes.

For the React version, use the files in the root directory and run:
```bash
npm run dev
```
